Das Problem

Quellen verschwinden.
PDFs bleiben.
Aktualisierungen werden zur Archäologie.

Diese Schleife läuft jedes Mal, wenn Sie ein Dokument schreiben, das länger lebt als ein Projekt. Die großen Werkzeuge — Confluence, Notion, SharePoint, Obsidian — wollen Konten, Installationsrechte, Netzwerk. Auf einem gesperrten Kundenlaptop, im Postfach einer Behörde, im Mail-Anhang an einen Wirtschaftsprüfer kommt davon nichts durch.

Also frieren Sie das Dokument als PDF ein.

Und verlieren die Quelle.

— Jeden Monat. In jedem Unternehmen. Seit den Neunzigern.

Die Lösung

Eine HTML-Datei, die gleichzeitig Viewer, Editor und Artefakt ist.

Sie laden die Datei herunter. Sie öffnen sie im Browser. Sie lesen, Sie editieren, Sie speichern eine neue Version. Keine Installation, kein Konto, kein Server, kein Internet.

01 / Format

Markdown nativ.
Mermaid eingebaut.

Sie schreiben in der Syntax, die Sie ohnehin kennen. Diagramme und eingebettete Bilder rendern automatisch — ohne Plug-ins, ohne Konvertierung.

02 / Umgebung

Eine Datei.
Komplett offline.

Marked und Mermaid sind in der HTML eingebacken, kein CDN, keine Internet-Abhängigkeit. Im Flugzeug, auf dem Kundenlaptop, überall.

03 / Bedienung

Lesen und Editieren
in derselben Datei.

Eine IndexedDB-Werkbank fängt jede Änderung ab, auch wenn der Tab zugeht. Speichern bleibt eine bewusste Geste — kein Auto-Save-Schreck.

04 / Verbreitung

Die Datei vermehrt
sich selbst.

Aus jeder dokufix-Datei lässt sich eine neue, leere erzeugen. Eine Datei durch die Firewall — und Sie haben die ganze Werkbank im Kundennetz.

05 / Export

Andere Systeme
einfach befüllen.

Sauberer Markdown-Export jederzeit. Confluence- und Jira-Syntax folgen als nächste Ausgabeformate. Sie schreiben einmal — und spielen denselben Inhalt überall ein. Kein Plattform-Lock-in.

06 / Audit

Das Dokument kennt
seine eigenen Änderungen.

Optionale Commit-Nachrichten beim Speichern werden in der Datei mitgeschrieben. Versionszähler, Zeitstempel und Änderungsprotokoll stehen direkt darin.
