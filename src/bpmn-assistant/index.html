Dokufix BPMN Assistant

Prozessdiagramme mit einem Sprachmodell schreiben und von dokufix anordnen lassen.

Sie beschreiben den Ablauf, das LLM schreibt daraus BPMN-XML, und dokufix ordnet das Diagramm selbst an, ohne dass Sie ein Element von Hand platzieren.

  1. LLM vorbereiten. Kopieren Sie die Handreichung für LLMs und geben Sie sie Ihrem Sprachmodell zusammen mit einer Beschreibung Ihres Prozesses: Wer ist beteiligt, wer tauscht mit wem Nachrichten, welche Schritte gibt es, wo wird entschieden, was läuft parallel?
  2. Rendern. Fügen Sie das gelieferte XML unten ein oder laden Sie es als Datei hoch. Sie sehen die Anordnung von dokufix (A2), auch mit mehreren Pools, Pools ohne eigenen Prozess (Black Box) und Nachrichtenflüssen. Hat die Datei eigene Koordinaten, steht ihr Bild darüber als „Original BPMN“.
  3. Feinschleifen. Die Bilder sind Vorschläge. Laden Sie die beste Variante als .bpmn herunter und bearbeiten Sie sie in einem BPMN-Modellierer wie dem Camunda Modeler oder demo.bpmn.io nach.
  4. Weiterverwenden. Laden Sie die fertige Datei wieder hoch, um sie zu prüfen, und nehmen Sie das Bild als .svg oder .png in Ihre Dokumente, in den gewählten Diagrammfarben.
